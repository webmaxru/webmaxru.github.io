Shared interaction model

Observe → analyze → stage → inspect → confirm

Each page registers JavaScript tools through document.modelContext.registerTool(). The agent operates on the same visible, deterministic state as the person. Consequential commitment remains a normal visible page action rather than a WebMCP tool, while ordinary browser safety policies continue to apply.
